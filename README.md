# 🍃 纳西妲 · 与你相识

一个会动、会说话、会记住你们日常的 **2D 二次元小女友**。默认 **Live2D 二次元模式**(碧蓝航线明石猫娘模型),角色身份是 B 站 VTuber **永雏塔菲**——傲娇猫娘、爱说"喵"、偶尔整活喊"关注塔菲喵"!由 DeepSeek AI + Edge 神经网络语音驱动。

> 📦 GitHub 仓库:https://github.com/f20880479-lab/nahida-live2d

## ✨ 功能

- **Live2D 二次元模式(默认)**:2D 手绘动漫感,嘴型同步、眨眼俏皮眨眼、情绪表情(眉毛/嘴型)、头部跟随鼠标、点击触摸互动、17 个动作循环
- **3D 模式(后备)**:3D 女孩 + 真实动捕待机(骨盆/脊柱/头/手臂),Live2D 加载失败自动回退
- **关系成长系统**:从「🌱 初识」→「🌿 相识」→「🌼 熟悉」→「🔥 亲近」,聊得越多,她对你的态度越熟络
- **AI 大脑**:DeepSeek 驱动,塔菲人设——傲娇粘人、句尾带「喵」、偶尔「关注塔菲喵,关注塔菲谢谢喵!」
- **Edge 神经网络语音**:晓伊音色(语速音调已调成俏皮风格),失败时自动回退浏览器在线神经音色
- **长期记忆**:她记得你们聊过什么,关系进度也会保留
- **语音输入**:点 🎤 用麦克风说话(需要 Chrome/Edge)
- **氛围彩蛋**:音乐盒背景音乐 ♪、夜晚模式 ☾(萤火虫粒子)、森林绿叶飘落、自定义称呼
- **零成本**:无 Key 也能玩(本地温柔回复),配 Key 后全 AI 驱动

## 🚀 快速开始

```bash
# 1. 安装依赖(只需一次)
npm install

# 2. 启动
npm start
# 或 node server.js

# 3. 浏览器打开
#    http://127.0.0.1:5179
```

也可以直接双击 `启动纳西妲.bat`。

## 🔑 配置 DeepSeek(推荐)

> 从 GitHub 克隆后,`config.json` 不会随仓库下发(含密钥,已被 .gitignore 排除)。请先复制模板再填入密钥:

```bash
copy config.example.json config.json   # Windows
# cp config.example.json config.json   # macOS / Linux
```

然后编辑 `config.json`:

```json
"deepseek": {
  "apiKey": "sk-你的key",
  ...
}
```

申请地址:https://platform.deepseek.com (按量计费,很便宜)。不填 Key 时纳西妲会用内置的本地回复,也能玩。

## 🎛 玩法

| 操作 | 说明 |
|---|---|
| 聊天框发送 | 和她说话,注意看她的表情和关系变化 |
| 🎤 麦克风 | 语音输入,说完自动发送 |
| ♪ 音乐 | 音乐盒风格 BGM |
| ☾ 夜晚 | 切换深夜氛围,萤火虫飞舞 |
| ⚙ 设置 | 自定义她对你的称呼、语音/音乐/夜晚开关 |

> 💡 关系阶段每聊 10 句提升一档,从初识到亲近,她的语气和亲密度会自然变化。
